Загрузить данные подразделения

Каждый файл приходит с анкетой: зачем данные, за какой период, как часто обновляются и кто отвечает. Без этого число в дашборде нельзя подписать источником — а значит, нельзя принимать по нему решение.

Вход подразделения

Логин и пароль выдаёт администратор дашборда. Администратор заходит под логином admin.

Анкета и файл

Краткое название, которое будет видно в списке загрузок.

Без ответа на этот вопрос число в карточке дашборда — просто цифра, а не основа для решения.

За какой период собраны данные. Будет показан в карточке показателя.

PDF, DOCX, XLSX, CSV, MD, TXT, HTML. До 50 МБ. Повторная загрузка того же файла (по содержимому) не допускается — откроется уже существующая проверка.

По умолчанию «разово» — система не будет сигналить о просрочке. Выберите реальную частоту, и дашборд покажет «просрочено», если данные не обновятся вовремя.

Кто отвечает за эти данные и ответит на вопросы ректора.

Конфиденциальные файлы хранятся в базе и индексируются для ИИ-поиска — так решено владельцем системы. Уровень доступа ставьте честно, это видно в списке загрузок.

Можно выбрать несколько — список берётся из настоящих показателей дашборда. Если не выбрать — документ просто попадёт в базу знаний, и ИИ сможет ссылаться на него в ответах.
